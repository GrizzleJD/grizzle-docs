# The Games

Grizzle launches with three games. Each one plays differently, so there is something for every type of player. All three give XP, and you can try practice runs without an account before you decide to join.

## At a glance

| Game | Style | How XP is earned | Maximum per game |
| --- | --- | --- | --- |
| [Dumpster Defense](dumpster-defense.md) | 3D defense against waves | 1 point = 1 XP | 4,000 XP |
| [Trash Bash](trash-bash.md) | Arcade, whack the raiders | 10 XP per point | 1,500 XP |
| [Crew Match](crew-match.md) | Memory cards, four levels | Clear all four levels | 1,500 XP |

## Which game should I start with?

* **Want something quick?** Start with Trash Bash
* **Like puzzles?** Try Crew Match
* **Want the biggest XP and the deepest game?** Play Dumpster Defense

Playing all three each day also helps you finish the Daily Challenge. See [The Reward System](../rewards.md).
